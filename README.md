# PolyGlot - Application PWA d'Apprentissage & Traduction (v2 avec Filtrage Vocal)

## ⚡ Nouveauté de cette version v2 :
- **Nettoyage vocal intelligent :** La saisie vocale supprime automatiquement les hésitations (*euh, hum, genre, bueno, este...*) ainsi que les répétitions de mots pour obtenir une phrase propre et fluide avant traduction.

## 📦 Déploiement sur GitHub Pages :
1. Dézippez le fichier ZIP.
2. Déposez les fichiers dans votre dépôt GitHub.
3. Activer GitHub Pages dans Paramètres > Pages.
